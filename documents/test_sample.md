# Artificial Intelligence Sessional Project: VoiceMate
## Overview
VoiceMate is an autonomous desktop voice assistant agent developed for Windows laptops.
It supports bilingual voice interactions in Bengali and English, system controls,
browser automation with Browser-Use 1.0, and document intelligence powered by PyMuPDF.

## Key Features
1. Hands-free typing mode for active desktop applications.
2. Battery status monitoring and low-power notifications.
3. High-performance document parsing and summarization.
4. Intelligent Google and YouTube searches.
